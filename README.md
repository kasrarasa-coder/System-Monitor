## 📌 Overview

**Pulse** is a lightweight desktop system monitoring project focused on providing a simple, elegant, and distraction-free way to understand what is happening inside your machine.

Instead of relying on heavy dashboards or complicated terminal commands, Pulse provides an intuitive interface where users can quickly observe:

- CPU activity
- Memory utilization
- Network throughput
- Disk usage
- Running processes
- System performance indicators

The project aims to create a monitoring experience that is informative without becoming intrusive.

---

## ✨ Features

### 🖥 Live System Monitoring

Pulse provides real-time visibility into important system metrics:

- CPU usage and temperature monitoring
- Memory and swap statistics
- Network activity visualization
- Disk storage information
- Active process overview


### ⚡ Lightweight Design

The goal of Pulse is efficiency.

Key principles:

- Minimal resource consumption
- Fast updates
- Clean user interface
- No unnecessary background overhead


### 🎨 Developer-Focused Interface

The interface follows a modern developer aesthetic:

- Dark theme
- Terminal-inspired typography
- Minimal animations
- Information-first layout
