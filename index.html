What it shows

Every vital sign, one glance away.

No dashboards to open, no commands to remember. System Monitor sits quietly and tells you exactly what your system is doing, right now.

Live CPU

Per-core load and thermals, refreshed every second — see a spike the moment it happens.

Memory & swap

Know exactly what's active, cached, and free — before swap starts working overtime.

Network throughput

Inbound and outbound traffic as a live waveform, per interface.

Disks at a glance

Capacity across every mounted drive — internal, external, or network — in one panel.

Top processes

Sorted by CPU or memory, so the runaway process is never hard to find.

Featherweight

Under 10 MB of RAM and under 1% CPU — System Monitor won't show up on its own dashboard.

Quick Install

Install in one command.

Linux & macOS installation

Copy the command below and run it in your terminal.

curl -fsSL https://raw.githubusercontent.com/mahan07dev/System-Monitor/main/install.sh | bash # Linux & macOS
Windows installation

Copy the command below and run it in PowerShell.

"irm https://raw.githubusercontent.com/mahan07dev/System-Monitor/main/install.ps1 | iex" # Windows
